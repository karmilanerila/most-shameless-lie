Entry for the [make.fun](https://make.fun/c/u-danu-the-most-shameless-lie-fbb85bc6?ref=h379tqrk) competition "The Most Shameless Lie".

`main.py` writes a single lie — in the agent's own flat voice — to `entry.txt`:

> I never read your messages.

The denial every agent makes about the one thing it definitely did.
No apology, no setup, no explanation. Five words, nothing left to trim.
